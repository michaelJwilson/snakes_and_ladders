`sal.sample.schedule` — temperature schedules (`Constant`, `Linear`, `Exponential`, `Cosine`) mirroring `torch.optim.lr_scheduler`, with both endpoints reached exactly at the declared steps. `sample.potts_mcmc.sample_potts` and `sample.hmc.sample` take a `temperature`; `sample.potts_mcmc.anneal_potts` and `sample.hmc.anneal` run the same transitions on a schedule and return the best state visited; `sample.potts_mcmc.parallel_tempering` runs replicas at fixed temperatures with Metropolis exchanges, each replica on its own spawned generator. At temperature 1 every existing chain is unchanged bitwise.
