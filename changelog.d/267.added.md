`snakes_and_ladders.opt.schedule` — temperature schedules (`Constant`, `Linear`, `Exponential`, `Cosine`) mirroring `torch.optim.lr_scheduler`, with both endpoints reached exactly at the declared steps. `search.potts_mcmc.sample_potts` and `opt.hmc.sample` take a `temperature`; `search.potts_mcmc.anneal_potts` and `opt.hmc.anneal` run the same transitions on a schedule and return the best state visited; `search.potts_mcmc.parallel_tempering` runs replicas at fixed temperatures with Metropolis exchanges, each replica on its own spawned generator. At temperature 1 every existing chain is unchanged bitwise.
