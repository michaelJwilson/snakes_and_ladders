The `sim/` package's bare-tuple returns --- `PottsGraph.compressed_adjacency`, `incidence` and `endpoints`, `count_pairs.split_covariate`, `css.sample_x_error` and `convolutional.encode_stream` --- return a frozen dataclass named for what it carries: `CompressedAdjacency`, `Endpoints`, `ChannelCovariates`, `XError`, `Encoded`.
Each iterates in its old tuple order, so every caller unpacking one is unchanged and every pinned array is the same array (issue #865, the `sim/` pull request of four).
