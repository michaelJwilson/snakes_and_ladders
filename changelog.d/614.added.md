`pytest -m <problem>` selects every test exercising one problem — `potts_lattice`,
`tree_jc`, and the 16 others the fixture registry declares — across the modules it
spans. The markers are added at collection from the fixture call each test module
already makes (`tests/_problems.py`), not written by an author, and compose with
the kind and tier markers: `-m "potts_lattice and critical"` is the intersection.
