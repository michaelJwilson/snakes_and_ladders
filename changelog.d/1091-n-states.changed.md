The state count is the field's (#1091, `n_states`). **Breaking:** `iterated_conditional_modes`, `alpha_expansion`, `alpha_beta_swap` and `simulated_bifurcation` read `n_states` from the field's state axis; the positional `n_states` is gone, and an optional `n_states=` keyword is checked against the field. `sim.potts.states_of(field, n_nodes, n_states=None)` is the one reading. Callers keep their stated count as the keyword, so every run is bitwise the run before.
