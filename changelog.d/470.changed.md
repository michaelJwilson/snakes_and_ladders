`pyproject.toml`'s marker list and `DEV.md`'s tier table are written from `infra/gates.py` by `infra/ledgers.sh`, each between marker comments, instead of being copies a test asserts (#470). The generated blocks are byte-identical to what they replace, so no marker text, budget or cap moves; `infra/ledgers.sh --check` fails a branch whose blocks were edited where they are read rather than where they are written, at 0.07 s added to that gate. Only the blocks are generated — the prose around them stays hand-written. The two assertions in `tests/regression/test_gates.py` that held those copies are retired; the copies a generator cannot take, `.github/workflows/ci.yml`'s conditions and the shell scripts' exports, stay asserted, because each is read by a tool that cannot import Python at the point it needs the value.
