A chain's transition kernel may be a function of position (#653).
`forward_backward`, `sample_path` and `forward_log_likelihood_from_density`
take either one `(K, K)` matrix for the whole chain, as every caller passed
before, or `(T - 1, K, K)`, one matrix per transition, so a spacing between
sites or a rate that varies along the sequence has a signature to arrive
through. The constant form is a stride-zero view of the same block of memory
and the choice between the shapes is hoisted out of the recursion, so it sums
the same terms in the same order: the single-matrix result is reproduced
bitwise in the evidence, the posterior, the pairwise posteriors and the sampled
path, and the constant path runs at 0.990x of the recursion that preceded it at
`T = 100,000`, `K = 8`. The varying form costs 1.044x there, and 512 B against
48.83 MiB in the kernel argument — `T` copies of the same numbers when it does
not vary, which is why the matrix shape stays rather than being subsumed.
