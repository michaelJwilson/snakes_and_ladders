`infra/reap_worktrees.py` retires a worktree once its branch is gone from the remote, which is the signal a merged or closed pull request leaves behind and needs no API token. A tree is kept if any tracked file differs, or if it holds an untracked file that is not a build artifact or a cache; a stash is not a reason to keep one, because stashes live in the common `.git` directory and survive the removal. `--dry-run` reports without removing. `infra/new_worktree.sh` created worktrees and nothing retired them: this host reached 56 against 9 open pull requests.
