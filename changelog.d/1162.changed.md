One torch forward recursion: `forward_log_likelihood_from_density` and the Baum–Welch Python E step both call `sal.opt.hmm.forward.forward_messages`, which walks a padded `(n, L, m)` density under a kernel of shape `(m, m)`, `(L - 1, m, m)` or `(n, L - 1, m, m)` and gathers each chain's evidence at its own last position (issue #1162). Both callers return the same values bitwise as before, gradients included.
