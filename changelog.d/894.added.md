`snakes_and_ladders.opt.starts`: one loop that benchmarks where a fit starts against what it reaches on an `Objective`. `StartsBenchmark` runs every start over the instances and seeds through `opt.budget.compare`, polishes each at a held budget through `opt.fit.fit`, `opt.emission_mixture.expectation_maximization` or Baum-Welch, and records each cell's curve under `track`; `SolverComparison` returns the host-stable table, the seconds per phase, the curves and each start's docstring and hyperparameters. `snakes_and_ladders.qa.starts` draws the standard two-panel figure and sets the LaTeX table from it. `infra/seeding_sweep.py`, experiment 010's test and `qa/mixture_seeding.py` call it; `track.MemoryRun` stamps each entry with the clock it arrived at.
