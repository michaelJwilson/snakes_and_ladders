`bound.Surrogate.__call__` returns a `float` where it returned a `torch.Tensor`, and `bound` imports no torch (#1011): a surrogate is a function of a discrete structure and the data, with no continuous argument to differentiate in, and every caller (`certify`, `search.infer`'s ranking, `likelihood.features`) read it through `float()`. `PlugInLikelihood`, `ParsimonyUpperBound`, `BlockFrequencyBound` and `learn.ranking.LearnedTreeSurrogate` return `float` with it; the protocol landed in #308 after release 0.3.0, so no shim is kept. `parallel.map_tasks` no longer imports torch to set `intra_op_threads`: it sets the count at once where torch is loaded, and through an import hook where a body imports it, so a NumPy body runs without torch in the caller or any worker. Median of 5 fresh interpreters: `import snakes_and_ladders.bound` takes 65 ms at 26.6 MB peak RSS, was 1,365 ms at 620.6 MB; a serial NumPy `map_tasks` at `intra_op_threads=1` peaks at 29.6 MB, was 620.9 MB, and a two-worker process map at 30.0 MB over the process tree, was 621.1 MB. The four surrogate classes' 180 values (six claims, 15 topologies, two alignments) are bitwise unchanged.
