`snakes_and_ladders.validation`, the home for external frameworks the package is checked or timed against (#972). Each framework is one `validation-<framework>` extra and runs in a subprocess: `validation.runner.run` writes the inputs to an `.npz`, runs the framework's script under the same interpreter, and reads back its outputs and the seconds it measured around the framework's own call. No file outside `validation/scripts/` imports a registered framework, asserted from the AST. Tests live in `tests/validation/`, carry the new `validation` marker, skip where their extra is absent, and run in CI's `validation` job, which installs every extra `infra/validation_extras.py` reads from `pyproject.toml`. A `goal` marker names a runtime the package has to meet: an external framework's on a declared fixture, measured on the reference host and hardcoded, so a goal test needs no framework installed. Goal tests fail until met and run in a non-blocking step of that job.
