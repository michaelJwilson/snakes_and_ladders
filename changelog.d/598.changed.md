`likelihood.potts.log_weights` scores every edge in one gather below 128 configurations and keeps its per-edge Python loop above it. The crossover is measured, not assumed: over lattices from 18 to 2,048 edges the gather wins 1.68x to 2.77x at 128 configurations and 2.4x to 5.4x below 96, while at 256 it runs from 0.72x to 1.70x, so the threshold sits below the mixed region. The loop is what the function always did, so the other branch is never a regression. The two sum the same terms in a different order and agree to 3.8e-16 relative, pinned at 1e-12 — the tolerance `maxflow.energy` already set for the same reason. `PottsGraph.endpoints` carries the edge columns the gather indexes with, derived once per graph as `incidence` is.

`search.maxflow.FlowNetwork.from_arcs` builds a whole network without a Python call per arc, grouping the arcs with the same counting sort `incidence.SparseIncidence` uses and handing back the list of lists Dinic wants. `alpha_expansion` builds its expansion network through it: the network was assembled in Python and solved in Rust, 76,928 `add_edge` calls against one `max_flow`. The arc order is preserved exactly — a minimum cut need not be unique and both solvers are pinned to one labelling — and a transcription of the loop it replaces is kept as its oracle, asserting arc for arc over 320 networks on open and periodic lattices at 2, 3 and 5 states and on Erdos-Renyi graphs.
