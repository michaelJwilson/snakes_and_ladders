Alpha expansion for Potts MAP at any label count (`snakes_and_ladders.search.alpha_expansion`), built from `snakes_and_ladders.search.maxflow`'s exact minimum cut one label at a time, with the single-site descent baseline it has to beat. It carries the repository's first proved approximation bound — within a factor 2 of the global optimum for a uniform Potts coupling — which holds at every size rather than only where enumeration reaches. Measured over 40 runs at an enumerable size it found the global optimum 39 times; past enumeration it beat the best of eight single-site descents on every trial.
