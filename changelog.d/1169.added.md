`opt.hmm.EmissionHmmObjective(observations, start, *, covariate=None)`: one HMM objective over any `EmissionFamily`, the joint count pair included, on segments of unequal length (`Ragged`) or a rectangular batch. `theta` maps each parameter by the family's declared domain, as `EmissionMixtureObjective` does; the value is `forward_log_likelihood_ragged`, and `value_and_gradient` takes the compiled `ragged_posteriors` E step and differentiates the Fisher-identity surrogate. It declares `blocks`, so `Restricted` holds any parameter fixed.
