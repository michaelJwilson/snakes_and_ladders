Every `oxi_snakes_and_ladders` kernel releases the GIL (#604). The nine
kernels each extract their slices and then touch no Python object, so the
work runs inside `Python::detach`. No arithmetic and no serial timing moves;
what changes is that `snakes_and_ladders.parallel`'s `backend="threads"` has
eligible sites for the first time. Four Python threads on the Potts sweep
took 4.03x the wall of one before and 1.14x after, throughput 0.99x to 3.51x.
