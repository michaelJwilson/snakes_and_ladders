A low-density parity-check code as the fourth problem class: Gallager's regular ensemble as offsets into one edge array (`sim.ldpc.gallager_code`), the binary symmetric, erasure and Gaussian channels behind one log-likelihood-ratio interface, a GF(2) encoder at `n <= 512` asserting `H c = 0`, the `from_parity_check` factor-graph adapter, a vectorized flooding decoder with the `tanh` rule and min-sum and a syndrome stop (`likelihood.ldpc.decode`), codeword enumeration for exact bit posteriors and the ML codeword at `n <= 24`, and density evolution on the erasure channel. The decoder is pinned to the general sum-product on six loopy codes and to enumeration on a cycle-free one; the 19,998-bit (3,6) code brackets the published threshold 0.4294 at the release gate.
