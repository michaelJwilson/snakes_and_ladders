Every start `sal.search.mixture_starts.lookup` returns is a `MixtureStart`:
it declares `polishes`, true only for a best-of that polishes every seeding,
and answers `polished(instance, rng, *, seconds, passes, tolerance)`. A plain
start and a seeded best-of seed, then polish once; a polished best-of is
unchanged. A caller no longer asks `isinstance(start, BestOf)`.
