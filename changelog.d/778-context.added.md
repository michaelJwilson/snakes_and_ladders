`Tracker.scalar` takes an optional `context`, Aim's own per-series key: the same name under two contexts is two series, so one loop records one quantity for each of its rungs without a name per rung. `MemoryTracker` keys a series by `(name, context)` and reads it back with `series(name, context)` and `last(name, context)`; `NullTracker` ignores it and `AimTracker` passes it through. `opt.langevin.mala` and `opt.slice.slice_sample` record per draw what their chains report, `search.annealed`'s three estimators per rung (`log_z`, `ess`, and simulated tempering's `occupation` under `{"rung": k}`), `search.potts_mcmc.parallel_tempering` and `search.tempered`'s ensembles the exchange acceptance of each adjacent pair, and `opt.schedule.adapt_ladder_by_round_trips` what each round placed. Every series still ends at the field its result returns, and the untracked run is unchanged: a hook whose inner loop is one call per rung runs it only under `tracker is not NULL_TRACKER`, the shared default instance, now a public name.
