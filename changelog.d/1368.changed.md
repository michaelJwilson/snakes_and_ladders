The Potts anneal and sample loops run in Rust, one `oxisal.potts_loop` call per run, by default wherever every move has a Rust kernel (single-site, both Swendsen-Wang, both Wolff): 201x to 373x the Python loop on a Wolff anneal at 256x256, 1.1x to 1.4x on single-site, the default there by the owner's principle that Python is not the step caller. `anneal_potts` and `sample_potts` take `loop_backend` (`Backend.PYTHON` replays the previous stream); `anneal_potts(polish=Polish.ICM)` polishes inside the same call. `iterated_conditional_modes` and `merge_small_labels` default to the new Rust ICM, bitwise the numba kernel (0.92x to 1.12x its time), by the owner's decision on simplicity rather than the 2x rule; `Backend.NUMBA` and `Backend.PYTHON` remain as oracles. A seeded anneal or chain on those moves changes stream.
