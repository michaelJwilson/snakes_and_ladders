The import package `snakes_and_ladders` is renamed `sal`, and its source tree `python/snakes_and_ladders/` is `python/sal/` (issue #1048). No alias is kept: `import snakes_and_ladders` raises `ModuleNotFoundError`, and every import changes from `snakes_and_ladders.X` to `sal.X`, the extension's to `sal.oxisal`. The distribution, the repository and the `run_snakes_and_ladders` console script keep their names. `infra/rename_package.py` made the rename and can repeat it.
