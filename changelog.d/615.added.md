`infra/bin/uv` refuses `uv sync`, `add`, `remove` and a syncing `run` when the
environment they would write is a symlink, which is how ~55 worktrees share
one. Put it ahead of `uv` on `PATH`; `infra/new_worktree.sh` emits the line.
A real `.venv` directory is never refused, so CI and a first install are
unaffected.
