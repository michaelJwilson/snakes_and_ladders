The `likelihood/` package's thirteen public entry points that returned a bare tuple return a frozen dataclass named for what it carries --- `DistanceMatrix`, `TreeDistances`, `Spectrum`, `Adjacency`, `Extremes`, `Posteriors`, `EmissionTables`, `EmissionRows`, `TreeMessages`, `StepKernels`, `EnergyBounds` --- each iterating in its old tuple order, so every caller unpacking one is unchanged and every pinned array is the same array (issue #865, one pull request per package).
