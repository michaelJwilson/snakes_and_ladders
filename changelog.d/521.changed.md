A ticket body and a pull-request body carry at most 40 content lines; blank lines, headings and HTML comments are not charged. `infra/check_pr_body.py` refuses a longer pull request in the `pr-title` job and names the count, the issue templates state the cap for an author, and both charge it with `infra/experiments.py`'s `body_lines` — the same function the ten-line experiment cap uses, so the repository has one meaning for how long a text is. Detail that does not fit belongs where it is refereed, a measurement in `STATUS.md` or a sweep in an experiment file, which is the ruling issue #458 made for experiments.
