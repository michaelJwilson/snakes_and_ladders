measurement declares rather than bitwise. `tree_search/ci`'s
`maximized_log_likelihood` is 45 L-BFGS fits: ten recomputations on one host
reproduce the committed record exactly, and a GitHub runner differs from it in
26 of the 45 values, by 4.365e-15 relative at the widest, which failed a pull
request that changed only docstrings, comments and LaTeX. That measurement now
records `rtol` 1e-12 relative — 229 times that noise, and 14 times inside the
smallest regression measured, a 10x loosening of the fit's own convergence
test, which moves 14 of the values by up to 1.434e-11 relative. Every other recorded value declares no
tolerance and keeps exact equality, as do seeds, budgets, algorithms and
library versions. No committed number changed.
