`infra/attribute_problems.py` and its guard are removed. The script was
scaffolding for #622 step 1: it read which problem each unmarked test module
exercises by scoring the module's imports against every catalogue row. Its
output has been consumed — 51 modules attributed, of which 13 build no
declared instance, 16 build one, 10 build two and 12 build three or more — and
`PROBLEMS.md`'s `Defines` column now states directly what the scoring
inferred, so a second, weaker reading of the same fact is a source of drift
rather than a check on one.

`infra/problem_join.py`'s join is removed with it. The three checks it sat
beside are kept, in `infra/document_orphans.py`: a figure the QA manifest
renders that no document cites (#492), a problem statement with no box in the
release checklist, and the `critical` assertion that no textbook source names
code, which is what the one-way key (#249) exists to protect. 327 lines become
201, and the `--check` mode goes, because nothing that remains gates.
