`snakes_and_ladders.track` is the one seam a run reports through: `track(name, tracker=...)` binds a `Tracker` to a `contextvars.ContextVar` for the block, `current()` reads it, and `NullTracker` --- the default outside any block --- makes every method a no-op. `opt.fit.fit`, `opt.hmc.sample`, `opt.hmc.anneal`, `opt.hmc.parallel_tempering`, `search.potts_mcmc.anneal_potts`, `search.potts_mcmc.parallel_tempering`, `search.tempered`'s two ensembles and `qa.figure.write_qa_figure` record once per iteration, sweep, round or figure. Every number recorded is one its result dataclass already returns, so a series ends at the field, and no default, draw order or return value changes: the untracked run is bitwise what it was. `MemoryTracker` keeps the record for a test, `AimTracker` writes an Aim run where `aim` is installed by hand --- it is declared in no extra, PYSEC-2026-1087 and PYSEC-2026-1088 standing unfixed against its current release --- and `peak_rss_bytes` and the state's bytes are recorded at the end of a chain, an annealing run and a tempered run.
