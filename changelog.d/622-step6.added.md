The textbook carries a table of every instance the registry declares, and the
shape each fixture states in its own words (#622 step 6).

**Not "size".** The tiers of one problem differ in more than one quantity at
once -- extent and state count, taxa and sites, chain length and transition
rate -- so a column that collapsed to a scalar would say the one thing it must
not. A guard asserts that no row names a single field.

**Generated, and it names no code.** Every declared field outside a small
not-shape set -- the seed, the tolerance, the loader, the oracle, a digest --
is printed, nested structures excepted: a transition matrix and a tree are the
instance's parameters rather than its extent. The field names are the fixture
file's own words, set as text and not typewriter, since typewriter is how this
repository sets code and the existing guard refuses it. A field a fixture
declares appears the day it is written and nobody maintains a list of what to
print.

One row per declared instance, and the problem cell names every catalogue row
that declares it, since two problems may be stated at one instance. Forty rows
do not fit a float, so it is a `longtable`, which is the one package the
preamble gains.
