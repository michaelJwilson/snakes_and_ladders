`sal.emissions.rising.log_rising` and `digamma_rising` run as one compiled `numba` pass per element; `log_rising` takes the plain `gammaln` difference wherever its own rounding bound meets the 1e-14 promise. At 25 x 2,829 pairs: `log_rising` 14.8 ms to 2.1 ms, `digamma_rising` 12.7 ms to 3.1 ms; the first call of a process compiles for about 1.2 s (#1329).
