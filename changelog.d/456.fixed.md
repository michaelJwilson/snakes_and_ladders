The test-duration guard is applied in the process that decides the exit
status, so a run distributed with `pytest-xdist` can no longer pass a test
that is over `SAL_DURATION_CAP`. Recording each duration in the process that
ran the test left the controller with an empty list: at a 0.05 s cap the
serial run failed naming two tests at 22.5 s and 7.8 s, and `-n 2` passed
naming none.
