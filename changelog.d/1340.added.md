`sal.emissions.coded` scores the count emissions on coded observations
(issue #1340, stage 1): `encode` codes integer counts per distinct value in
Rust (no label axis: labels fold into the code, `x + Z·y`), giving an `int32` inverse, a weight per code and the covariate per
observation, and `log_emission` builds the tables at the distinct counts
only, completes the covariate term per observation and gathers, bitwise
equal to `emissions.dense.log_emission` on the same observations.
