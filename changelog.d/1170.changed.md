`likelihood.forward_backward.sample_path` draws by inverting each step's CDF at `rng.random(T)` rather than calling `rng.choice` per position, so it is the one-segment oracle of `ragged.sample_paths`. It consumes the generator as before, one uniform per position, and the draw at position `t` reads the `(T - 1 - t)`-th, as `rng.choice` did; a seeded path changes only where a uniform falls within rounding of a CDF step.
