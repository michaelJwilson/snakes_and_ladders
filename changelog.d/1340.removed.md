`sal.emissions.dense.log_emission`, `sal.emissions.dense.Order` and `sal.oxisal.dense_log_emission` are removed (#1340, stage 3). `Order` read one table in one order since #1336. The dense log-emission is `sal.emissions.coded.log_emission(family, Dense(counts, covariate))`, bitwise equal to the removed call on its six test cases; no caller outside the tests used the removed call. **Breaking:** `from sal.emissions.dense import log_emission` or `Order` fails.
