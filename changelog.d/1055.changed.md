Iterated conditional modes moved to its own module, `search.icm`, with `SweepOrder`; `Labelling` stays in `search.alpha_expansion`, which both import. **Breaking:** `from sal.search.alpha_expansion import iterated_conditional_modes` (or `SweepOrder`) now fails; import from `sal.search.icm`. The field parameter is renamed `field_values` to `field`. A new `min_sites` floor dissolves, after each sweep, every state holding `0 < count < min_sites` sites into `surviving[floor(u * m)]`, `u` a uniform drawn up front, `rng.random(max_sweeps * n_nodes)`, after the start and the permutations; `min_sites = 0`, the default, draws nothing and is the descent before, bitwise on both backends at `spatio_only` ci and release, seeds 0 to 4. `ground_state(..., backend=None, min_sites=0)` passes both to `icm` and `icm-random` and every other method refuses them by name; `descend`, `run_icm`, `run_icm_random`, `spatio_sequential.label_step` (ICM only) and `potts_starts.polish_by_icm` take `min_sites`. `search.numba.icm.icm_sweeps`, moved from `sample.kernels` to the `<subpackage>.<backend>` layout (#1059), is one kernel on the Rust sweeps' signature, `(state, field, offsets, neighbours, couplings, orders, draws, n_sweeps, stop_when_clean, min_sites)`, replacing `icm_sweeps` and `icm_sweeps_ordered`; `icm_sweeps_checked` validates shapes with the Rust entries' messages.
