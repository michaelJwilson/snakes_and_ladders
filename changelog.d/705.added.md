`snakes_and_ladders.learn.arena`: one five-row table per problem from one call
--- greedy, REINFORCE, actor-critic, PPO and MLP+PPO --- with **match** a
first-class outcome beside beat and lose (issue #705).

The rows existed and each was written for its own experiment, so the Potts chain
had all five, the tree three and the HMM path none, and a new problem cost a new
harness. The registry is a list of the five calls and nothing more: each learner
reached through it returns **bitwise** what calling its function directly returns
on the same streams, and the chain's five rows come back at 80.2 / 88.9 / 88.9 /
96.3 / 97.5% of its 81 starts.

A row reports the evaluations it spent beside the fraction it reached, because a
learner that *matches* an exact baseline has shown its policy class contains the
classical method, and one that matches it more cheaply has shown something
stronger. Neither is readable from a fraction alone.
