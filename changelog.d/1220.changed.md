Compiled chains run the package's own value+gradient kernels (issue #1220). An objective opts in through `supported_gradient() -> (kernel, data) | None`, which replaces the `DeclaredGaussian`, `DeclaredRosenbrock`, `DeclaredMixture` and `DeclaredGaussianHmm` protocols; `sample.declared.declared_energy` stays the one reader. The compiled route accepts any positive temperature.
