The single host build lock splits in two (`infra/locks.sh`): a `measure` lock
with one slot for anything whose number reaches a pull request, and a
`validate` lock with three for correctness runs nobody times. A measurement
takes both, so timings stay comparable, while three validations now overlap
where they used to serialize. `with_lock measure --wide` raises the thread
count for measuring code that is itself parallel; every other measurement
stays at one thread, since the recorded baselines were taken there.
