`snakes_and_ladders.oxi_snakes_and_ladders.max_flow` and `ising_ground_state` borrow their arguments as `float64` and `int64` NumPy arrays through `rust-numpy` instead of copying Python lists, and `ising_ground_state` returns an `int64` array instead of a list. `snakes_and_ladders.search.maxflow_rust` is unchanged in signature and returns the same configuration and energy, bitwise, at extents 16, 32 and 64. The caller-visible speedup over the NumPy reference moves from 6.1-10.5x to 6.3-10.7x; the kernel with its arrays built is 26-32x, and the remaining difference is measured to be the Python `energy` evaluation, not the boundary (#336).
