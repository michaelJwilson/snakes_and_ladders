`BranchLengthObjective` and `SubstitutionModelObjective` take `backend=Backend.JAX`: the value and gradient come from one `jit`-compiled pruning program per topology (`likelihood.pruning_jax`), within `1e-11` relative of the PyTorch route. The default stays `Backend.TORCH`: at 10^5 sites on 4–32 taxa JAX takes 0.95–1.59× the taped route's runtime and 1.23–1.56× its memory (`infra/jax_decision.py pruning`).
