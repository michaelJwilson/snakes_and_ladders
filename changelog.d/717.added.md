The root of `snakes_and_ladders` exports the seams the package declares --- `Objective`, `Environment`, `FactorGraph`, `PottsGraph`, `fixture`, `Backend` and `parallel` --- each resolved on first use, so `import snakes_and_ladders` loads no submodule; the placeholder `double` is no longer exported from the root (issue #717). Every package resolves its submodules on first use as well, so `sal.sim.tree` reads as written after `import snakes_and_ladders as sal`.
