`sim.spatio_sequential.simulate_spatio_sequential` draws a family whose
observation carries axes of its own -- the two-channel count pair among them
(#672). It reshaped each class's draw to `(S, n_m)` and allocated an `(S, V)`
buffer, so a pair family's `(S * n_m, 2)` draw raised and there was no axis to
hold the channels. It now reads the family's trailing axes from the draw and
returns `(S, V, ...)`; one instance still holds one observation shape across
its classes, and a mismatch is refused by name.

`_drawing_covariate` carried the same defect as #670 one module over,
appending the broadcast singleton to a covariate that already had the family's
channel axis. A scalar-observation fixture draws bitwise what it drew before.
