The count-pair simulators draw under the model's covariate, in NumPy and in
Rust (#671). `sim.count_pairs.simulate_count_pairs` passed none, so the one
problem class whose emission *is* a pair had no planted covaried instance and a
fit conditioned on a covariate there had nothing to recover.

`src/count_pairs.rs` takes one flat `S * V` array per channel rather than the
`(S, V, 2)` the model holds, because each is read at a different point of the
draw. **The exposure scales the drawn gamma rather than the distribution**:
`c * Gamma(r, mu / r)` is `Gamma(r, c mu / r)` exactly, so the per-(class,
state) distribution objects stay and a covariate costs one multiply per draw
instead of a construction. The successes' covariate replaces the declared trial
count, which bounds the channel outright.

Binning sums the covariate over each bin with the counts it accompanies, since
that is the exposure the binned count was drawn at. Under a covariate the
negative-binomial aggregate is exact only where the exposure agrees *within* a
bin -- the same conditional exactness the successes channel already carries,
now stated for both.

A fixture that declares no covariate draws exactly what it drew before, which
is asserted rather than assumed.
