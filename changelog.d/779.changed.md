Reinforcement learning moved out of `snakes_and_ladders.search` into
`snakes_and_ladders.learn`: `search.rl` is `learn.tree` (490 lines, the
phylogenetic environment), `search.gym` is `learn.gym` (206, the Gymnasium
adapter) and `search.surrogate` is `learn.ranking` (323, the learned surrogate
seam). `search.potts_mcmc` now defines `MoveKind`, which `learn.potts_nd`
spelled out rather than importing.

The three old paths remain as shims that re-export every public name and emit
one `DeprecationWarning` on import; they are removed in the release after
0.3.0. Nothing else changed: no reward, feature, policy, default, RNG order or
return value moved, and the ten test modules that moved pin the same values
from the new paths.
