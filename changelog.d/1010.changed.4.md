`snakes_and_ladders.emissions` is a package: the 3,778-line module splits into `base` (the protocols, `Reestimate`, the refusals and the covariate rule, 436 lines), `families` (categorical, Gaussian and the variance floor, 528), `mstep` (the count M-step solves, their bounds and `M_STEP_BACKEND`, 1,254) and `counts` (the five count families, 1,594), and `__init__` re-exports the module's 26 public names under an explicit `__all__`, so every `from snakes_and_ladders.emissions import X` is unchanged and setting `emissions.M_STEP_BACKEND` still selects the route. A private name stays in the module that defines it: the solves `counts` calls and the kernels the tests pin are public in `mstep` (`solve_dispersion`, `solve_beta_binomial_rust`, `NoTails`, ...), `lgamma_shifted` in `counts`, and a shared helper belonging to neither would go in an underscore-prefixed submodule under a public name (#1010, C1).
