The CSS code `Hx = Hz = H` defines over a bicycle matrix, with decoding scored
on the *coset* of the error rather than on the error: distinct errors sharing a
syndrome can act identically on the codespace, so `e == e_hat` is the wrong
question and `(e + e_hat) in rowspace(H)` replaces it.

Three decoders on one partition of the errors. Exact degenerate maximum
likelihood, summing each coset's probability, is the floor at **0.070297**;
the likeliest single error reaches 0.072735, so degeneracy is worth 3.4% and
changes the returned coset at 24 of 128 syndromes. Belief propagation reaches
0.178750 +- 0.005788, **2.54x the floor**, and the CSS condition is the reason:
`H H^T = 0` forces even row overlaps, an overlap of two is a four-cycle, and
the graph carries 30 at n = 16 and 160 at n = 96. Its failures are counted
apart, because they invert with size: non-convergence is 81% of them at n = 16
and 38% at n = 96.

`sim.ldpc` gains `gf2_rank`, `gf2_inverse` and the CSS condition as an exact
test. `docs/experiments/` admits `bicycle-css` as a problem, the first whose
success criterion is a coset.
