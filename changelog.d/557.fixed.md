The label guard no longer reports a test's own document fixtures as dangling
citations. `tests/regression/docs/test_problem_join.py` builds a textbook in
`tmp_path` and writes `sec:aaa`, `sec:bbb` and `sec:zzz` into it, which the
guard read as three citations of labels no document defines. The exemption
list it joins is now itself checked, so a module that stops authoring
document text is reported rather than silently exempted.
