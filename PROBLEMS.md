# Problems

The problems this repository supports, one row each, with the code that simulates, evaluates, fits, searches and learns on it. Every cell is a symbol or a path that exists in the tree; `tests/regression/test_problems_catalogue.py` resolves each one, so a row cannot outlive what it names. `STATUS.md` says how far each has got; `CHECKS.md` lists the checks each rests on.

An **oracle** is the independent answer an evaluator is pinned to: an enumeration, a brute-force sum, or a closed form that shares no code with the thing it checks.

What every row shares: `snakes_and_ladders.opt.fit.fit` fits it, `snakes_and_ladders.opt.hmc.sample` samples its posterior, `snakes_and_ladders.opt.fit.standard_errors_at` puts an interval on any fit of it, and `snakes_and_ladders.opt.schedule.Schedule` tempers it. That is the claim `ROADMAP.md` §1.1 makes and the import-graph tests keep true.
