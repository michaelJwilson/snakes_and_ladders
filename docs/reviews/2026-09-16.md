## 3. Quality

Is each claim established by what refereed it, and is any of it theatre.

- **The oracle rule holds where it was checked.** `src/count_pairs.rs` (553
  lines) and `src/ragged.rs` (257) each carry a Python reference the tests pin
  them to; the pair fit's blind recovery is stated with its band (×1.99 and
  ×2.11 against E[U(0.25, 4)] = 2.125, 12%).
- **Three guards pass on shape and cannot see the content they stand for.**
  `test_planning_documents_agree.py` compares milestone-id sets, so a missing
  Milestone 2.2 section passes because `TICKETS.md` carries the id (#683).
  `test_problem_statements_complete.py` checks eleven stems, so a key sharing a
  section is unseen (#681). `infra/check_notebooks.py` checks that the last
  cell is Further Work and names an issue, so a Further Work item that landed
  stays "not built" (two found, fixed).
- **13 applicability cells are empty and the table cannot say why** (#684):
  not applicable, not run, or run and unrefereed read the same.
- **The gate has two holes.** A stacked pull request runs no checks, and
  retargeting does not start them (#685). `select_tests` did not select
  `tests/regression/opt/test_opt_hmm.py` on #667 although that module imports
  the code #667 changed, so every gate passed and three consecutive
  push-to-`main` runs failed on that one test until #680 (#688). The second is
  the failure mode `infra/CLAUDE.md` names: a selection that guesses narrowly
  is a test that silently did not run.
- **Not audited:** the assertion bodies of the 2,969 tests for coverage
  theatre beyond the kind markers, and the committed figures against a fresh
  render; both are release-gate work and are recorded as not done.
