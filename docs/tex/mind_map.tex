% The mind map (issue #664). One page, radial: `snakes_and_ladders` at the
% centre, the two concerns around it, the packages beyond, and every module on
% the outer ring.
%
% The tree is `docs/tex/generated/mind_map.tex`, written by `infra/mind_map.py`
% and not committed --- a drawn copy of the tree is what `SEAMS.md` was before
% issue #601 deleted it. Every coordinate is computed there; nothing here
% places a node. Each branch takes a wedge proportional to the leaves it
% carries, so every leaf gets the same angle, and a leaf's label runs radially
% outward because 115 horizontal labels 3.1 degrees apart would collide.
%
% Plain TikZ: `forest` would pack a tree but its `environ`, `trimspaces` and
% `elocalloc` are absent from this TeX Live, and TikZ `graphdrawing` needs
% LuaLaTeX where the build runs pdflatex.
